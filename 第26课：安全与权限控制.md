## 1. API Key 认证

### 1.1 当前实现

```python
class AuthGuard:
    def __init__(self, settings: Settings):
        self._api_key = settings.api_key

    async def __call__(self, x_api_key: str = Header(alias="X-API-Key")) -> str:
        if not x_api_key:
            raise MissingApiKeyException()   # 400
        if x_api_key != self._api_key:
            raise InvalidApiKeyException()   # 401
        return x_api_key
```

### 1.2 当前局限

- 只有一个全局 API Key（所有用户共享）
- 没有用户/角色/权限的概念
- 无法追踪"谁做了什么操作"

### 1.3 多 API Key 方案

```python
# 数据库模型
class ApiKey(Base):
    __tablename__ = "api_keys"

    id: Mapped[int] = mapped_column(primary_key=True)
    key_hash: Mapped[str] = mapped_column(String(64), unique=True)  # API Key 的哈希
    name: Mapped[str] = mapped_column(String(128))                   # 标识名（如 "张三的Key"）
    permissions: Mapped[str] = mapped_column(String(256))            # "read,write,admin"
    expires_at: Mapped[datetime | None] = mapped_column(nullable=True)
    is_active: Mapped[bool] = mapped_column(default=True)

# 认证逻辑
class MultiKeyAuthGuard:
    async def __call__(self, x_api_key: str = Header(alias="X-API-Key")):
        key_hash = hashlib.sha256(x_api_key.encode()).hexdigest()

        async with session_factory() as session:
            result = await session.execute(
                select(ApiKey)
                .where(ApiKey.key_hash == key_hash)
                .where(ApiKey.is_active == True)
                .where(
                    or_(ApiKey.expires_at.is_(None), ApiKey.expires_at > datetime.now(timezone.utc))
                )
            )
            api_key_record = result.scalar_one_or_none()

        if not api_key_record:
            raise InvalidApiKeyException()

        return api_key_record  # 返回包含权限信息的记录
```

## 2. 请求频率限制（Rate Limiting）

### 2.1 滑动窗口限流

```python
class SlidingWindowRateLimiter:
    def __init__(self, redis_client, max_requests=100, window_seconds=60):
        self._redis = redis_client
        self._max = max_requests
        self._window = window_seconds

    async def is_allowed(self, client_id: str) -> bool:
        now = time.time()
        key = f"ratelimit:{client_id}"

        # 移除窗口外的旧记录
        await self._redis.zremrangebyscore(key, 0, now - self._window)

        # 计数当前窗口内的请求
        count = await self._redis.zcard(key)

        if count >= self._max:
            return False

        # 记录本次请求（score = 时间戳）
        await self._redis.zadd(key, {str(uuid.uuid4()): now})
        await self._redis.expire(key, self._window)
        return True
```

### 2.2 集成到中间件

```python
class RateLimitMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, limiter: SlidingWindowRateLimiter):
        super().__init__(app)
        self._limiter = limiter

    async def dispatch(self, request, call_next):
        client_id = request.headers.get("X-API-Key") or request.client.host

        if not await self._limiter.is_allowed(client_id):
            return JSONResponse(
                status_code=429,
                content={"error": {"code": "RATE_LIMITED", "message": "Too many requests"}},
            )

        return await call_next(request)
```

## 3. 安全最佳实践清单

| 检查项 | 当前状态 | 建议 |
|--------|---------|------|
| API Key 复杂度 | min_length=8 | 建议 32+ 字符 |
| HTTPS | 依赖反向代理 | 生产环境必须启用 TLS |
| 输入大小限制 | max_file_size=50MB | ✅ 已防护 |
| SQL 注入 | SQLAlchemy 参数化查询 | ✅ 已防护 |
| CORS | 未配置 | 生产环境应设置允许的域名 |
| 密钥管理 | .env 文件 | 生产环境用 K8s Secrets / Vault |
| 日志脱敏 | 未脱敏 | API Key 不应出现在日志中 |
